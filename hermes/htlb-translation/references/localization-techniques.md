# HTLB Localization Techniques Reference

## Core Localization Principles

- **Fidelity first**: Preserve original meaning while adapting to Russian cultural context
- **Explicit annotation**: Always mark localizations with brackets [ ] to distinguish from original text
- **Consistency**: Apply same technique across all chapters for same type of realia

## Localization Techniques Catalog

### 1. Emergency Number Localization

**Technique**: Add country-specific equivalents in parentheses

**Example**: 
- Chinese: '遇到紧急情况请拨打120'
- Russian: 'в случае экстренной ситуации звоните 120 (для Китая — 112/103, для РФ — 103)'

### 2. Country-Specific Procedures

**Technique**: Add translator's comment with country-specific alternatives

**Example**:
- Chinese: '到当地派出所办理'
- Russian: 'обращайтесь в местный отдел полиции (в Китае —派出所, в РФ — участковый)'

### 3. Realia Glossing

**Technique**: Add brief cultural context in brackets

**Examples**:
- Chinese: '喝姜茶驱寒'
- Russian: 'пейте имбирный чай от простуды [в Китае — традиционное средство для прогревания]'
- Chinese: '给长辈磕头拜年'
- Russian: 'кланяются старшим в Новый год [в Китае — традиционный жест уважения]'

### 4. Unit Conversion

**Technique**: Add metric/Russian equivalent in parentheses

**Examples**:
- Chinese: '每天8杯水'
- Russian: '8 стаканов воды в день (≈2 литра)'
- Chinese: '跑了5公里'
- Russian: 'пробежал 5 километров (≷3 мили)'

### 5. Legal/Administrative Identifiers

**Technique**: Preserve byte-for-byte (not translated)

**Examples**:
- Chinese: '国食药监办〔2010〕432号'
- Russian: '国食药监办〔2010〕432号 (документ Государственного управления по контролю за лекарствами)'
- Chinese: '最高法知民终51号'
- Russian: '最高法知民终51号 (решение Верховного суда по интеллектуальным правам)'

### 6. Cultural Concepts

**Technique**: Add brief explanation with cultural context

**Examples**:
- Chinese: '关系'
- Russian: 'гуаньси [в Китае: неформальные связи и отношения, влияющие на бизнес]'
- Chinese: '面子'
- Russian: 'мяньцзы [в Китае: социальный престиж и репутация]'

### 7. Food and Cuisine

**Technique**: Add explanation or Russian equivalent

**Examples**:
- Chinese: '吃饺子'
- Russian: 'едят цзяоцзы [китайские пельмени с мясом и овощами]'
- Chinese: '喝绿豆汤'
- Russian: 'пьют суп из маша [в Китае — традиционное летнее блюдо]'

### 8. Historical References

**Technique**: Add brief historical context

**Examples**:
- Chinese: '改革开放'
- Russian: 'реформы и открытость [политика КПК с 1978 года]'
- Chinese: '文化大革命'
- Russian: 'Культурная революция [1966-1976, период политических потрясений]'

## Implementation Rules

- **Always use square brackets [ ]** for localization annotations
- **Keep annotations concise** — 1-2 sentences maximum
- **Place annotations immediately after** the localized term or phrase
- **Never alter original meaning** — localization is adaptation, not correction
- **Maintain readability** — don't overload text with excessive annotations
- **Standardize terminology** — use same Russian terms for same Chinese concepts across chapters

## Quality Control

- Review all localizations for accuracy and cultural appropriateness
- Ensure annotations don't disrupt text flow
- Verify that technical/legal terms are preserved correctly
- Check that units and measurements are converted accurately
- Confirm emergency numbers and procedures are correctly localized
