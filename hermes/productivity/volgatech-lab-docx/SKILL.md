# Учебные документы Волгатех (ПГТУ): лабы и отчёты по практике

Образец-эталон лабы: `~/university/архив (прошлые семестры)/Метрология_лаба_долгирев.docx`.

## Отчёт по практике

Оформление по ГОСТ (титульник, дневник практики, аттестационный лист, основная часть) — см. `references/practice-report-gost.md`. Эталонные примеры одногруппников искать в `~/Downloads` и `~/university`; методичка/ГОСТ-файл в `~/university` — главный источник, при конфликте: методичка > бланк-образец > ГОСТ. Целевая папка результата: `~/university/<Тип работы> (<Фамилия И.>)/` — точное имя сверять с существующей папкой предмета.

## Титульный лист (порядок и выравнивание)
1. По центру, TNR 12, КАПСОМ, 4 строки: «МИНИСТЕРСТВО НАУКИ И ВЫСШЕГО ОБРАЗОВАНИЯ РОССИЙСКОЙ ФЕДЕРАЦИИ» / «ФЕДЕРАЛЬНОЕ ГОСУДАРСТВЕННОЕ БЮДЖЕТНОЕ ОБРАЗОВАТЕЛЬНОЕ» / «УЧРЕЖДЕНИЕ ВЫСШЕГО ОБРАЗОВАНИЯ» / ««ПОВОЛЖСКИЙ ГОСУДАРСТВЕННЫЙ ТЕХНОЛОГИЧЕСКИЙ УНИВЕРСИТЕТ»».
2. 7 пустых строк.
3. По центру, TNR 14 bold: «Отчет по лабораторной работе» / ««Тема работы»» / (опц. «Вариант № …») / «по дисциплине» / «Название дисциплины».
4. 3 пустых строки.
5. Справа: «Выполнил студент гр. ИТС-41(з):» / «Долгирев Леонид Михайлович» (ФИО полностью, не инициалы!), «Проверил:» / «ФИО преподавателя полностью».
6. 3 пустых строки, по центру: «Йошкар-Ола» / «2026».

Контроль: титульник обязан умещаться на первой странице — считать высоту (строки × размер × 1,5 × 1,18 / 28,35 = см) против 25,7 см доступных (А4 29,7 − поля 2+2). Если блоков больше (например, есть строка «Вариант №…»), пустые строки сокращать в первую очередь.

## Общее оформление
- Times New Roman 14, полуторный интервал, абзацный отступ 1,25 см.
- Поля: верх/низ 2 см, левое 3 см, правое 1,5 см.
- Ответы на контрольные вопросы: вопрос bold, ответ обычным.
- Графики по центру шириной ~15 см, подпись курсивом 12 под рисунком («Рис. N. …»).
- Выводы по результатам — обычным текстом после таблиц/графиков.
- python-docx: номера страниц через `w:fldSimple` с instr `PAGE` в footer.

## Контекст пользователя
- Группа ИТС-41з (в старых работах встречается ИТС-31 — старое, сейчас 41з).
- В docx — только отчёт/ответы; код — в ноутбуке/скриптах; имя файла: `ЛР<N>_Долгирев_ИТС-41з.docx`; всё zip-архивом.
- Проверяющий: «Проверил(а)» + ФИО полностью.
