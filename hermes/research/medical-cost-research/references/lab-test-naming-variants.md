# Lab Test Naming Variants

Lab tests are known by many names across providers and languages. This reference helps map common variants for accurate pricing research.

## Russian Lab Test Names

| English Name | Common Russian Variants | Notes |
|---|---|---|
| Complete Blood Count | ОАК, общий анализ крови, клинический анализ крови | Most basic blood test, includes WBC, RBC, platelets, hemoglobin, hematocrit, leukocyte formula, ESR |
| Lipid Panel | Липидограмма, липидный профиль, липидный комплекс, холестериновый профиль | Measures cholesterol (total, LDL, HDL), triglycerides |
| Glycated Hemoglobin | Гликированный гемоглобин, HbA1c, гликозилированный гемоглобин | Average blood glucose over past 2-3 months |
| Alanine Aminotransferase | Аланинаминотрансфераза, АЛТ, ALT | Liver enzyme, capillary vs venous pricing may differ |
| Aspartate Aminotransferase | Аспартатаминотрансфераза, АСТ, AST | Liver enzyme, capillary vs venous pricing may differ |
| Gamma-Glutamyl Transferase | Гамма-ГТ, ГГТ, GGT | Liver enzyme, also called gamma-glutamyl transpeptidase |
| Total Bilirubin | Билирубин общий | Liver function test, breakdown into direct/indirect often available separately |
| Direct Bilirubin | Билирубин прямой, билирубин связанный | Liver function test |
| Total Protein | Общий белок | Measures albumin + globulin |
| Uric Acid | Мочевая кислота | Gout marker, kidney function |
| Creatinine | Креатинин | Kidney function marker, often with eGFR calculation |
| Urea | Мочевина | Kidney function marker |
| Thyroid Stimulating Hormone | ТТГ, тиреотропный гормон | Thyroid function test, TSH is the standard abbreviation |
| Vitamin D | Витамин D, 25-OH vitamin D | Often measured as D2 + D3 total, or separately |
| Folic Acid / Folate | Фолиевая кислота, фолаты, В9 | Vitamin B9, important for cell division |
| Ferritin | Ферритин | Iron storage marker, deficiency indicator |

## Provider-Specific Naming

- **Gemotest:** Uses Russian names consistently, complex tests like "Biokhimia 13" bundle multiple tests
- **Helix:** Similar naming to Gemotest, sometimes with slight variations
- **Invitro:** May use more technical or Latin-based names
- **International:** English names are standard outside Russia, but local variants exist

## Search Tips

- Use exact-match search with the most common variant in the target region
- When in doubt, search for both Russian and English names
- Check if "complex" or "panel" versions cover individual tests needed
- Note if venous vs capillary blood affects pricing

## Complex Test Bundles

Many providers offer bundled tests at significant discounts:
- "Biokhimia 13" (Gemotest): 13 biomarkers for 1690 rubles vs 3500+ separately
- "Lipidogramma" bundles cholesterol + triglycerides + HDL/LDL
- "Thyroid panel" typically includes TSH + T3 + T4

Always verify the bundle covers all required individual tests before choosing the bundle option.
