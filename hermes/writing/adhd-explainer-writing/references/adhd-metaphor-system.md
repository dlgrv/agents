# ADHD engagement techniques + consistent metaphor system

## Consistent metaphor system (reuse across articles, don't invent a new one per article)

Cross-article consistency beats variety: the reader builds one mental world.

| Концепция | Метафора |
|---|---|
| Производная / наклон | Крутизна дороги/тропы под ногами |
| Вес (w) | Ручка настройки прибора туриста |
| Bias (b) | Стартовая высота на высотомере |
| Градиентный спуск | Кран в душе: крутишь на ощупь; большой рывок = кипяток (перелёт через минимум) |
| Скорость обучения α | Длина шага туриста: маленький — надёжно, но долго; большой — перепрыгиваешь дно |

| Loss одного примера | Штраф за один неверный шаг |

| Цепное правило | Эстафета шепотков: усиления перемножаются по цепочке |
| Вычислительный граф | Рецепт по шагам / карта тропы: кружки — контрольные точки |

## Evidence-based ADHD engagement techniques (for review briefs)

- Self-constructed visualization beats passive images AND retention lasts (still measurable a month later) — when possible, ask the reader to sketch/draw the example themselves, not just look at a figure.
- Gamification = instant feedback + goal-directed challenge, not «fun»: worked examples with immediately checkable answers (checkpoint «Если можешь пересказать») map onto this.
- Choice increases engagement: offering optional depth paths («если хочешь вывод — по ссылке») leverages this.
- Metacognitive routines (STOP-THINK-ACT-REVIEW style checkpoints) are the most effective single technique for ADHD error reduction — the «пересказай и листай дальше» checkpoints are this pattern; place them at least every 2-3 paragraphs in long calculation blocks, not only at section ends.
- Visual organizers/schematics help inattentive-type readers most; kinesthetic/step-by-step interaction helps hyperactive-type most.

## Review brief template (paste into reviewer subagent goals)

1. Для каждого крупного понятия — есть ли бытовая аналогия рядом с первым появлением? Если нет — предложи конкретную из системы выше.
2. Где ADHD-читатель потеряет нить (точное место): абзацы >1 мысли, серии символов без напоминания, >30 строк без чекпоинта.
3. Оценка 1-10 «запомнит ли смысл через неделю» (не «понял ли формулу»).
4. Топ-N правок с точным местом.
