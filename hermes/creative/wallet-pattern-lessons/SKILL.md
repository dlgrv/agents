# Уроки лекал кошелька (v1→v5)

## Конструкция
- Каждый шовный путь обязан иметь дырку на ОБАХ концах (открытый U/L-шов). Длина пути = сумма сегментов; дуги U-углов суммарно = π·r (не 2π·r).
- ЕДИНАЯ СЕТКА дырок: шаг низа подбирается так, чтобы все точки подкладок/карманов были подмножеством точек тела (зеркальные половины включительно). Иначе фазы 5.00 vs 5.02 мм разъезжаются и стопку не прошить одним проходом. Тест: `set(liner) <= set(body)` в системе координат тела.
- Дырка на линии сгиба корпуса — только на теле; на деталях половин её НЕТ (шов через сгиб не делают).
- Прорези (слоты) НЕ делать без запроса: пользователь отверг («зачем отдельная прорезь, если карман = 2 куска кожи, сшитые низом»). Классический карман: перед яруса пришит низом к стопке, вход сверху, шов-упор ВИДЕН на 1 мм ниже кромки переднего яруса (T-slot, Borderland Leather).
- Каскад без прорезей: низы ярусов ПОДНИМАЮТСЯ к лицу (0/0.5/1.0), верхи ОПУСКАЮТСЯ (5.4/4.7/4.0) — вход каждого кармана свободен, карта торчит язычком над передним ярусом; язычок ≥ 1 см.
- Внутренность бифолда = 3 ДЛИННЫХ куска со сгибом у корешка (тело / разделитель купюр / подкладка с карманами), а не 2 половинки — так просил пользователь; разделитель обязателен, иначе купюры падают под карманы.
- Высота бифолда под сложенную купюру 78.5 мм: высота ≥ 78.5 + шов 4 + кромка. 7.9 см — купюра выглядывает; честный минимум 8.3 см. Не заявлять «помещается» без арифметики.
- Прямые углы по запросу: контур-прямоугольник ЗАМКНУТ (все 4 кромки!) — matplotlib дорисовывает хорду на незамкнутом пути, и кромка оказывается в 1.6–2.3 мм от дырок.

## Процесс
- Сторонний аудит (delegate_task) ловит то, что собственные проверки пропускают: незамкнутые контуры, текст за листом, шаг = L/N вместо L/(N-1). Запускать ДО отправки пользователю.
- Пользователь просит ОДИН PDF на всё задание (не страницы по отдельности).
- Тест-сьют: геометрия из exec() генератора (единый источник правды), печать — pypdf (размер страницы) + pymupdf get_drawings (векторные контуры 1:1) + пиксельный рендер для полей/цветов. Пиксельные замеры отдельной детали хрупки (размерные линии в окне) — контуры мерять векторно.
- ГЛАВНЫЙ класс багов разметки: смешение ЛОКАЛЬНЫХ и МИРОВЫХ координат. Фильтр `y <= TIER_T[t]-SEAM` по мировым side_ys для детали с локальным нулём на TIER_B[t] даёт дырки ВНЕ детали (ярус высотой 3.0 получал дырку на y=3.4). Правило: для каждой детали генерировать точки в её системе (0..W × 0..H), проверять `0.4 <= y <= H-0.4`; тест должен сверять локальные с локальными.
- Тесты TDD ловили и свои ошибки: двойной учёт угловых точек (перекрёстная строка, совпадающая с боковым швом) — вычитай own_perimeter из ожидания; устаревшие критерии после смены дизайна («карта целиком внутри яруса» в каскаде с язычком неверна) — переписывай критерий, а не геометрию.
- Купюры по первоисточникам: 5000р 157×69 (ЦБ РФ), €50 140×77 (ЕЦБ), $100 156×66.3; пополам макс 78.5. Карта ISO/IEC 7810 ID-1 85.60×53.98×0.76.
- Поля: весь контент > 3 мм от краёв; ys.max() считать от ВЕРХА картинки (в image-координатах y=0 сверху); подписи над рядами деталей не должны выходить за лист. Подписи длинных кусков: va="bottom" влево от левого верхнего угла детали — заголовок по центру (ha="center") уезжает к верхней кромке листа, когда стопка поднята.
